# yadc-si

An SI unit system following the [yadc](../) pattern, generated by
[`yadc-codegen`](../yadc-codegen/) from
[`yadc-codegen/si.toml`](../yadc-codegen/si.toml). It is one example of a
system *you* could own: every modelling choice here (the kilogram as the
base unit of mass, the radian as a base unit, which coherent units print by
name) is in that TOML file.

What it defines:

- `SIUnit` - the unit: a product of named units to integer powers. The base
  units are the metre, kilogram, second, ampere, kelvin, mole, candela and
  radian (`rad`: solid angle is rad², torque J/rad, so an angular speed
  never mixes with a frequency). Its std `* / + -` return `Option`.
- `SIQuantity<U, N, IS_BASE>` - a number `N` of the unit `U`, with
  `#[derive(const_derive_more::ConstOps)]`. `IS_BASE` says whether `U` is a
  base unit or a product of base units.
- `Exact` - the exact number unit sizes are written in, with std `From` to
  `f64`, `f32` and every primitive integer.
- Unit constants, one of each unit, counted in `Exact`: the 20 SI prefixes
  and the base units at the crate root (`KILO`, `METRE`), the rest in their
  family's module (`mechanical::KILOMETRE`, `thermal::CELSIUS`).
- Quantity aliases, `Length<N, U = metre, IS_BASE = true>`.
- `From` between a quantity of any unit and a base unit of its dimension,
  both ways.
- `dynamic::DynamicSIQuantity` - a quantity of a unit chosen at run time;
  and per quantity a unit enum, `dynamic::mechanical::LengthUnit`.

~120 quantities with ~400 units, in 9 feature-gated families:

| Feature | Examples |
|---|---|
| `mechanical` | Length, Mass, Time, Instant, Force, Energy, Power, Velocity, Acceleration, Frequency, Torque, … |
| `angular` | Angle, SolidAngle, AngularVelocity, AngularAcceleration, … |
| `electromagnetic` | ElectricCurrent, ElectricPotential, Capacitance, MagneticFlux, ElectricalResistance, … |
| `thermal` | ThermodynamicTemperature, TemperatureInterval, HeatCapacity, ThermalConductivity, … |
| `fluid` | DynamicViscosity, MassRate, VolumeRate, SurfaceTension, DiffusionCoefficient, … |
| `density` | MassDensity, LinearMassDensity, ArealMassDensity, VolumetricNumberDensity, … |
| `chemistry` | AmountOfSubstance, MolarMass, MolarConcentration, Radioactivity, CatalyticActivity, … |
| `photometric` | Luminance, LuminousIntensity, Illuminance, RadiantExposure |
| `information` | Information, InformationRate |

`dimensionless` (`Dimensionless`, with `PERCENT`, `PART_PER_MILLION`,
`DECIBEL`, `NEPER`, ...) is always present. All families are on by default;
`default-features = false` plus a feature list cuts compile time.

## Usage

A crate using `yadc-si` needs:

```rust
#![feature(generic_const_exprs)]
#![allow(incomplete_features)]
```

and `const_trait_impl` and `const_ops` to compute in its own `const` items.

```rust
use yadc_si::dimensionless::*;
use yadc_si::dynamic::DynamicSIQuantity;
use yadc_si::dynamic::mechanical::LengthUnit;
use yadc_si::mechanical::*;
use yadc_si::thermal::*;
use yadc_si::*;

// A number times a unit is a quantity of it; `.into()` converts it into
// the unit the target type names. Base units multiply into base units.
let mass: Mass<f64> = (154.0_f64 * POUND).into();        // 69.85 kg
let g0: Acceleration<f64> = (1.0_f64 * STANDARD_GRAVITY).into();
let weight: Force<f64> = mass * g0;
println!("{weight:.1}");                                  // 685.0 N
let newtons = f64::from(weight / NEWTON);                 // 685.03: a plain ratio is a number

// Any unit of a quantity, named in its type.
let d: Length<f64> = (3.0_f64 * MILE).into();
let miles: Length<f64, { MILE.unit() }, false> = d.into();
let n = f64::from(miles / MILE);                          // 3.0
let more = 0.5 * miles + miles;                           // 4.5 mi: one unit adds and scales

// A unit with a zero converts; it has no products.
let t: ThermodynamicTemperature<f64> = (25.0_f64 * CELSIUS).into();             // 298.15 K
let f: ThermodynamicTemperature<f64, { FAHRENHEIT.unit() }, false> = t.into(); // 77 °F
let rise: TemperatureInterval<f64> = (9.0_f64 * DEGREE_FAHRENHEIT).into();     // 5 K
// let nope = (25.0 * CELSIUS) * (1.0 * METRE);           // error: cannot multiply

// A log unit converts the same way: dBm on power, dB on a plain ratio.
let p: Power<f64> = (30.0_f64 * DECIBEL_MILLIWATT).into();              // 1 W
let dbw: Power<f64, { DECIBEL_WATT.unit() }, false> = (2.0 * p).into(); // 3.01 dBW
let ratio: Dimensionless<f64> = (10.0_f64 * DECIBEL).into();            // 10
let x = f64::from(ratio);

// A unit chosen at run time: every operator returns an Option.
let q = (DynamicSIQuantity::from(d) / DynamicSIQuantity::from(2.0 * SECOND)).unwrap();
let v: Velocity<f64> = q.try_into().unwrap();             // Err(q) for another unit

// A choice among a quantity's units, printed and parsed by its symbol.
let u: LengthUnit = "mi".parse().unwrap();
let in_miles = SIUnit::from(u).from_base(f64::from(d / METRE)); // 3.0
```

Physical constants are units of the quantity they measure:
`SPEED_OF_LIGHT`, `PLANCK_CONSTANT`, `STANDARD_GRAVITY`,
`GRAVITATIONAL_CONSTANT` (`mechanical`), `ELEMENTARY_CHARGE`
(`electromagnetic`), `BOLTZMANN_CONSTANT`, `STEFAN_BOLTZMANN_CONSTANT`
(`thermal`), `AVOGADRO_CONSTANT`, `MOLAR_GAS_CONSTANT` (`chemistry`).

## `std` and `no_std`

| Build | `Cargo.toml` |
|---|---|
| hosted (default) | `yadc-si = "0.1"` |
| `no_std` | `yadc-si = { version = "0.1", default-features = false, features = ["libm", "mechanical"] }` |

One of `std` and `libm` is required: a log unit's conversion needs `powf`
and `log` (`num_traits::real::Real`). `serde` works in either mode.

## Optional features

- `serde` — `SIQuantity` serializes as its number; the unit is the
  deserialization target's.
- `uom` — `From` / `TryFrom` between `SIQuantity` / `DynamicSIQuantity`
  and [`uom`](https://docs.rs/uom)'s quantities (uom's angle kinds become
  `rad` exponents).

## Regenerating

Everything in `src/` except `uom_bridge.rs` is generated. From the
workspace root:

```sh
cargo run -p yadc-codegen -- yadc-codegen/si.toml -o <dir>
```

then copy `<dir>/src/*.rs` and `<dir>/src/dynamic/*.rs` over `yadc-si/src/`
and `yadc-si/src/dynamic/`. The generated `Cargo.toml` is a starting point,
not this crate's. `uom_bridge.rs` holds orphan-rule impls that must sit
beside `SIQuantity`; `si.toml` lists it under `extra_modules`, so the
generated `lib.rs` declares it and the generator never writes it.

## Origin of the unit data

Symbols, labels and measured conversion factors are derived from the [`iliekturtles/uom`](https://github.com/iliekturtles/uom) project (MIT/Apache-2.0); a unit with an exact definition (inch, pound, standard gravity, survey foot, ...) is written from it (see `yadc-codegen/si.toml`).
